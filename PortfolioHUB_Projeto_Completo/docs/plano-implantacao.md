# Plano de implantação — PortfolioHUB

## Objetivo
Publicar um portfólio estático para centralizar projetos, com código versionado no GitHub e documentação apoiada pelo Google Gemini.

## Etapas
1. **Planejamento:** definir escopo, responsável, requisitos e critérios de aceite.
2. **Preparação:** criar conta/repositório GitHub e instalar Git; configurar editor.
3. **Implementação:** organizar HTML, CSS e JavaScript; inserir projetos reais.
4. **Versionamento:** registrar alterações com commits claros e enviar para o GitHub.
5. **Segurança:** revisar permissões, habilitar autenticação em dois fatores e procurar segredos.
6. **Testes:** verificar responsividade, filtros, busca, links e carregamento.
7. **Publicação:** configurar GitHub Pages a partir da branch `main`.
8. **Revisão:** testar o endereço público, corrigir falhas e registrar evidências.
9. **Apresentação:** demonstrar a interface, repositório, práticas de segurança e testes.

## Uso do Google Gemini
O Gemini pode ajudar a criar listas de verificação, revisar documentação, sugerir casos de teste e explicar erros. As sugestões devem ser validadas antes de serem aplicadas. Não compartilhar credenciais, tokens ou dados confidenciais.

## Critérios de aceite
- A página abre sem erros.
- Os cartões de projetos são exibidos.
- Busca e filtros funcionam.
- Layout é utilizável em desktop e celular.
- Repositório contém documentação e `.gitignore`.
- GitHub Pages publica a versão revisada.
- Nenhuma credencial está armazenada no código.
